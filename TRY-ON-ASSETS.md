# Fitting-room sample images

Generated with the built-in Imagegen tool. Project files: `public/images/try-on/model.png`, `jersey.png`, `tee.png`, and `hoodie.png`. Original generated images are preserved.

## Base model prompt

Use case: product-mockup. Create one photorealistic full body ecommerce fashion model studio photograph. An adult Indian male fashion model age 25 with medium brown skin, short dark textured hair, neutral pleasant expression, slim-average build, front facing, standing naturally arms slightly away from body hands beside thighs (not in pockets), feet shoulder width apart. Wearing plain fitted light gray short sleeve crew neck t-shirt tucked into straight dark charcoal trousers, off-white plain sneakers. Whole head and shoes fully visible, no cropping. Centered precise symmetrical pose, camera straight ahead, portrait image 2:3 aspect ratio. Warm ivory seamless studio background #eeede6, soft diffuse light, subtle floor shadow. Body occupies 88% image height. No logos no text no accessories no props. This image is the base for a clothing try-on UI.

## Outfit edit prompt (used once for each garment)

Edit target: first image is the base model photograph. Supporting garment reference: second image. Change ONLY the model's upper garment: dress him realistically in the exact garment from the second image, untucked, with accurate color, shape, seams, sleeve length, and any printed number/stripes. Preserve model identity, face, hairstyle, skin tone, exact pose, hands, trousers, sneakers, light, background, camera framing and image aspect ratio. Head and shoes stay at exactly same coordinates. This must be the same photograph with upper garment replaced, for a seamless animated try-on transition. Natural cloth drape, photo-realistic. No text, no new props.

Each edit references `model.png` and the matching product cutout from `public/images`: burgundy jersey, ivory tee, or slate hoodie. Background transparency is false for these model photographs.

## Frontend behavior

`src/TryOn.tsx` opens the fitting-room panel on product pages. It preloads the selected model photo, measures the product image and model torso, and runs a 1.25-second Web Animations transition. At 850 ms the model photo crossfades to the selected outfit. Reduced-motion users get the outfit change without the moving garment. Closing or leaving cancels pending animations; failed image loads expose a retry control.

This is a prepared-image style preview of the current product in its selected color. The fitting room, product image and flying garment follow the product color swatches. Additional model photographs cover jersey Ink, tee Sand and Charcoal, and hoodie Moss and Ink. These were generated by editing only the upper garment color while preserving the original model, pose and background. Colors are illustrative. The preview does not estimate customer size or fit, accept uploaded photos, or call an AI service at runtime. Rapid color changes and closing cancel outdated animation work.
